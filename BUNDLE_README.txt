Shadow — complete project bundle

This archive contains the editable Godot project source, all game assets, project/configuration files, tests and documentation. It also includes the managed web shell in site/ and the matching Godot Web export in dist/.release/ (including index.pck and index.wasm).

Open project.godot with a compatible Godot 4 installation. The .godot editor cache, Git history, and temporary test/build scratch were omitted; Godot can regenerate editor imports, and the provided Web export is retained.
