## 中英双语 / Language

- 标题页右上角和暂停菜单均可切换「中文 / English」。切换立即生效，不重开关卡。
- 菜单、操作提示、战斗状态、任务、对白、结尾字幕及加载页均支持双语。
- 语言偏好保存在独立的 `user://ying-language.cfg`；Web 同步至本地存储以供下次加载页使用，不改动通关进度与最佳时间。
- 首次运行按系统语言选择：中文系统使用简体中文，其余使用 English。
- 编辑 `data/i18n.json` 添加或调整翻译。原始中文是稳定键，剧情源继续保存在 `data/story.xml`；修改剧情时同步维护文本、说话人和组合对白键。
- 延续原版图片、动画、关卡与音频。为兼容当前运行时，UI 使用模板内置 ManusCC0 + CJK 字体链；原像素字体素材仍保留。
- 标准开发检查为 `npm run check`；导出包检查为 `npm run check -- --pack`（需先准备当前发行候选）。`npm run dev` 使用当前 Manus 安装提供的 `GAME_RUNTIME`，不会启动下方历史 README 中的旧服务器。
- 开发预览保留原调参工具；正式发行投影排除开发面板与本地调参覆盖，不改写游戏默认值。

以下为随原版源码提供的历史说明，具体运行、检查与版本保存以当前 Manus GameDev 工作流及 `package.json` 为准。

# Shadow

**《影》**是一款原创、可在浏览器中游玩的 Godot 4.7 动作游戏，核心体验是一击生死、敌意预判、专注慢动作、子弹弹反、即时重演与竞速通关。

## Controls

| Action | Keyboard | Touch |
|---|---|---|
| Move | `A` / `D` or arrow keys | Left/right buttons |
| Jump | `K` | Up button |
| Drop through a one-way platform | Hold `S` / down arrow, then press `K` | Hold down, then tap up |
| Directional slash dash / reflect | Hold `A`/`D`/`W`/`S` or arrows, then press `J`, `X`, or left click | Slash button uses facing direction |
| Focus slow motion | `L` or `Shift` | Focus button |
| Rewind room | `R` | — |
| Pause / resume | `Esc` | Pause button |
| Live tweak panel | `F1` or `P` | — |

## Rules

The title now identifies the game as **影** and deliberately contains only the title, controls, start prompt, and the Story Prologue / Boss Test actions. The former eyebrow, slogan, premise, divider, speedrun record copy, and corner tagline have been removed. On a new save, **按任意键 // 开始剧情** opens the narrative prologue automatically; after the prologue has been completed once, the prompt changes to **按任意键 // 继续第一关**. Returning players can always select **剧情序章 // 从任务简报开始**, while **首领测试 // 守门人** jumps directly into the current boss encounter.

The tutorial is now the opening chapter rather than a detached training room. A television shutter opens on a cinematic generated image of a battered flip phone lying on a rain-wet surface. The handset is deliberately defocused in the background; the encrypted contract is presented as an independent, sharp foreground text column instead of being forced into a fake phone screen. The mission is to destroy a mysterious “cargo” held by the **赤井帮**, first by breaching its outer compound. **Every formal story line types on character by character with a subtle retro electronic tick.** The `J // 继续` prompt appears only after the line is complete; pressing `J` during typing reveals the full line, and pressing `J` again advances. When the shutter reopens on the apparently empty rooftop, a procedural lightning bolt strikes the left side; 影 materializes at the impact point in a true idle pose, and the first enforcer blurts an XML-editable surprise line before the formal confrontation. After the first two Chinese combat lessons, four new gunmen visibly run in from the right before shouting. Their four rounds are staged as a single horizontal row rather than a vertical cluster. Completion still requires one real Focus-assisted rightward dash slash using `L + D + J`; it reflects all four rounds and kills all four shooters before 影 runs offscreen and the television shutter closes.

During the main run, `Esc` opens an always-processing pause menu over the frozen room. It provides **Resume**, **Restart Run**, **Replay Story Prologue**, and **Return to Title** actions; BGM, rain ambience, and currently active gameplay sound voices pause and resume with the scene. The prologue action unpauses safely before changing scenes. The menu remains responsive while the SceneTree is paused, and touch players receive a dedicated pause button.

The player and every enemy are defeated by one successful hit. The promoted default directional attack rectangle is **110 pixels long by 102 pixels wide**: 60 pixels forward, 50 pixels behind the origin, and 51 pixels to each side. The 0.33-second attack animation contains 12 frames. A stationary slash now deals damage on zero-based frames **2–8**—the visible **3rd–9th frames**. Its animation-clock startup is approximately **55 ms**, preserving a brief visual preparation without the previous 138 ms lag. The active orange debug rectangle follows this exact window. It tests rectangle-versus-body overlap instead of an enemy foot pivot. Directional slash dashes retain continuous damage for the full displacement, as required for reliable path coverage. Bullets use explicit circular hitboxes; hostile and reflected projectiles test those circles against body capsules. Reflection reverses the incoming trajectory and triples its speed. **Every successful player-triggered projectile reflection now activates the same impact slowdown and camera punch used by a Warden melee parry.** A reflected bullet sweeps its complete per-frame movement segment against every living enemy and every hostile projectile. It destroys **all enemy bullets** crossed before its first hostile-unit impact without being consumed itself. Each intercepted round produces a short high-z burst of white-hot cores, scarlet metal streaks, deep-red fragments, and an expanding red shock ring; no blue particles are used. Interception reuses the same ElevenLabs steel-parry cue at a slightly lower level, and both particles and sound inherit the active Focus/parry time scale. When the reflected bullet finally crosses one or more enemy units, the earliest path intersection is killed regardless of array order or which gunner fired the shot, and the reflected bullet is destroyed immediately at that first unit contact.

Clearing the first rooftop and entering its orange gate records the clean-run time and changes directly to the **赤井帮室内据点** without showing an intermediate result menu. The second stage is now a **3,475-pixel-tall, five-floor** vertical assault: 影 enters at the bottom, climbs 12 alternating one-way catwalks through a cramped power-station hideout, and reaches the boss gate at the top. Holding `S`/down and pressing `K` drops through any upper one-way platform, so the player can descend to hunt survivors; the bottom floor is protected and performs a normal jump instead. Each floor begins as a lived-in rest area. **Only the first squad uses a flow-locking, J-gated story exchange.** On floors two through five, XML-authored NPC chatter begins as soon as a resting guard enters the camera—before 影 reaches that floor or combat activates—and never pauses movement, attacks, or progression. Alerts still activate floor by floor. Five ranged guards occupy jump-route platforms instead of every enemy standing on the main floor, creating elevated crossfire during ascent. Clearing all 14 guards opens the top gate and routes directly into the Warden scene.

The boss scene begins fully black: the television shutter opens to an exact **2.35:1** aperture while 影 and the Warden remain locked and all combat HUD/touch controls stay hidden. **The opening confrontation is intentionally music-free** so rain and XML-driven typewriter dialogue carry the tension. After the final `J` advance, the bars expand back to the normal **16:9** frame, combat unlocks, and the Warden’s exclusive faster 128-BPM cyber-noir lo-fi loop begins from its downbeat. **The Warden now has 25 health segments by default and is not killed in one hit.** Default katana damage is one segment, committed melee-parry damage is two, and reflected-round damage is two, so a fresh Warden requires thirteen returned rounds rather than falling after a few reflections. The Warden’s committed melee-parry and every reflected boss round use the same universal parry feedback as rooftop, tutorial, and interior bullets. When the Warden falls, the final heavy hit triggers a separate fixed **1.0-second, 0.5× finisher slowdown** across the Warden, rain, particles, and active sound; it is independent of the parry tuning controls. No victory chime plays, the combat theme stops, and the rain leads into his XML-defined final words only after the finisher beat completes. The shutter then closes and a five-beat animated comic epilogue begins. Slow push, pull, and pan motion follows 影 into the warehouse, toward a wooden crate, through the raised-katana beat and a small offscreen meow, then reveals a trembling calico exotic-shorthair cat. The sequence ends on a persistent black **TO BE CONTINUED...** screen; any key returns to the title.

The idle and run source silhouettes are taller than the attack sequence, so both now use the same restrained `1 / 1.18` correction around the shared foot baseline rather than the previous, overly small `1 / 1.30`. This removes the size jump between standing and running while preserving attack, jump, and defeat at their production scale. Each enemy elimination emits 34 short-lived, high-z crimson droplets and streaks from the torso, biased along the last slash direction and slowed by Focus with the rest of the simulation.

## Editable story data

Briefing text, tutorial dialogue, all five interior-floor conversations, the boss introduction and final words, comic titles/captions/order/timing, speaker labels, actor targets, and all level-one enemy threats live in [`data/story.xml`](data/story.xml). The `interior_floor_1` through `interior_floor_5` blocks control who speaks before each indoor ambush; `member_0`, `member_1`, and `member_2` address the guards assigned to that floor. The `boss_arrival` block controls the opening confrontation, `boss_passed` controls the defeated Warden’s last lines, and `post_boss_epilogue` controls the five illustrated beats. Copying, deleting, moving, or rewriting `<line>` elements changes sequences without touching GDScript. Tutorial, interior, and boss actors are placed at collision-floor foot baselines before scripted freezes, while dialogue ends above the speaker’s head rather than across the face or torso. [`docs/STORY_EDITING.md`](docs/STORY_EDITING.md) explains every field and the boundary between editable text/timing and fixed visual direction.

## Live tweak panel

Press `F1` or `P` to open the panel. Settings are split into four focused tabs: **Player** for movement, jump, and Focus; **Combat** for attack motion, player collision, and universal parry feedback; **Enemies** for the shared enemy hurtbox, blade guard, gunner, and Warden behavior; and **Audio / Visual** for camera, character rim lighting, and the audio mix. The Combat tab’s **弹反反馈 // 全场景** section exposes **弹反慢放时长**, **弹反时间倍率**, **中心缩放强度**, and **中心缩放时长**. The camera pulse scales around the current screen center without adding any player-tracking offset, then restores the authored camera distance independently from the slower simulation. The Warden difficulty section remains focused on **生命格数**, **斩击伤害**, **弹刀伤害**, **反弹子弹伤害**, action cadence, and approach/volley speed. The shared enemy section still exposes **Body Width** and **Body Height** for ordinary hostiles, with the latest default set to a 30×97-pixel capsule. Changes apply immediately and persist in browser storage. The current page scrolls independently, while Export JSON and Reset Defaults remain fixed at the bottom. The mouse wheel scrolls pages only and never changes a slider value; values are adjusted by clicking or dragging. While the panel is open, the cyan player, red enemy, magenta projectile, and active orange attack hitboxes remain visible in the main level.

When the tune is ready, press the always-visible **导出调参文件** button. The Web build downloads `ying-tweaks-v16.json`, containing values from every tab and identifying the project as **影**. Version 16 promotes every value from the supplied `ying-tweaks-v15.json` into source defaults, including 25 Warden health, two-segment reflected damage, a 31×97 player capsule, 0.35-second attack cooldown, 0.30-second parry slowdown, and the restrained 0.02× / 0.28-second center zoom. Existing version-4 through version-15 browser values migrate forward without losing prior adjustments. **恢复默认值** restores this supplied baseline across all tabs.

The first room is 5,200 world units long and contains 12 melee and ranged enemies across floor routes and elevated catwalks. Each enemy receives a role-appropriate Akai-kai threat from the XML file, but only a randomized **56%** of ordinary enemies actually speak on a given run. A successful bark appears as plain white text above the enemy when the player enters encounter range, disappears after three seconds, and clears immediately if the speaker dies; a silent roll is consumed once rather than rerolled every frame. All six gunners use the same tested firing cadence, and projectiles remain valid across the full room. Platforms use one-way collision. The ninja jump launches at `1.35×` base force, applies `1.65×` ascent gravity and `1.45×` fall gravity for a fast arc with more than 230 pixels of theoretical height, and advances its 12 video-derived frames at the selected **18 FPS**. Clearing all rooftop hostiles activates the textured industrial exit gate; reaching it records the fastest clean run and advances to the vertical interior stage, then the Warden arena.

## Art and animation

All game UI now uses the project-wide **Fusion Pixel Font 12px Proportional `zh_hans`** build from upstream release 2026.08.11. The complete Simplified Chinese font—not a dialogue-only subset—is bundled, so adding new Chinese characters to `story.xml` does not require rebuilding the font. This fixes Web missing-glyph boxes and gives the title, task phone, world dialogue, HUD, pause menu, boss UI, and tweak panel one consistent retro-pixel voice. [`docs/FONT_NOTICES.md`](docs/FONT_NOTICES.md) records the source and version; the original SIL OFL 1.1 and relevant upstream license texts ship in `data/licenses/`. To stay below the 5 MiB Web cap, the exporter omits the inherited `assets/template/` sample art, which has no runtime references; all actual game art remains included.

The briefing background is an original, text-free 2560×1440 image generated specifically for this scene, then deterministically reduced to a 1280×720, 38 KB WebP by `tools/art_pipeline/prepare_briefing_background.py`. The selected composition places a softly blurred, unbranded flip phone in the right background, preserves a low-detail black region on the left, and uses rain beads, muted cyan reflections, and distant scarlet bokeh to connect it to the rooftop world. All exact Chinese story copy remains live Godot UI above the image, so XML edits stay immediate and no generated lettering can become garbled.

The post-boss epilogue uses four original, text-free 2560×1440 illustrations generated as one coherent **American independent cyber-noir comic** set rather than photographic or 3D imagery. Thick ink contours, cel-shaded blocks, restrained halftone texture, blue-black warehouse shadows, cyan visor/blade light, and small red emergency lamps stay consistent across the discovery, approach, pre-impact, and calico-cat reveal panels. `tools/art_pipeline/prepare_post_boss_panels.py` reproducibly resizes them to exact 1280×720 WebP runtime plates totaling about 327 KB. `scripts/post_boss_cinematic.gd` supplies the visual presets, slow Ken Burns-style movement, fades, skip input, and final black continuation screen; exact live titles, captions, order, and timing come from XML.

The interior stage uses one original, text-free **9:16 cyber-noir comic background** generated specifically as a tall side-view power-station hideout. Rainy barred windows, tired break spaces, switchgear, hanging cables, red alarm lamps, and broad architectural bands align the art with the authored collision route. The optimized 900×1600, roughly 117 KB WebP is repeated with overlap across the taller five-floor world rather than stretched; this preserves texture scale and the 5 MiB package budget. Runtime catwalk textures remain separate and match every real one-way collision rectangle.

The environment once again uses the **exact original 1600×900 rainy neon-noir skyline** from the first complete build. It is rendered with aspect-cover cropping and the original restrained blue-black wash. The experimental bright three-layer city and the later muted replacement are no longer runtime assets. Background parallax is intentionally **0×**: the image remains fixed to the rendered viewport while the camera, player, and full 240-pixel slash dash move through the level, eliminating skyline jumps and preserving the original composition at every encounter.

Gameplay surfaces are now a purpose-built **rain-wet industrial rooftop material set** rather than procedural rectangles. `scripts/environment_art.gd` renders alternating 640×90 steel roof modules across the full ground, texture-fits a cable-and-truss catwalk to every elevated collision rectangle, places four low-glow HVAC/power-service structures, and replaces the drawn exit arch with a weathered open-center security gate. The geometry and collision rectangles are unchanged, so traversal and tuned combat remain intact. All six runtime textures are optimized alpha WebP files totaling roughly 44 KB; `tools/art_pipeline/build_rooftop_environment.py` reproducibly removes the generator’s baked checkerboard, trims the authored shapes, creates the mirrored ground module, and exports production sizes.

The game now uses a fixed **1280×720, 16:9 logical frame**. Wider, taller, 4:3, and portrait browser windows scale that frame uniformly and show centered black bars instead of revealing extra world or stretching the art. The Audio / Visual tab still includes **Camera Distance** from `0.75×` to `1.60×`; the supplied `1.45×` default uses an approximately `0.69×` Camera2D zoom and reveals 45 percent more foreground world in each dimension inside the same 16:9 composition. CanvasLayer HUD and tweak UI remain pixel-stable, and the skyline renderer expands inversely with camera zoom so the background image does not scale or reframe.

Hero, blade-guard, and gunner motion follows the video-first process documented in [`docs/ANIMATION_PIPELINE.md`](docs/ANIMATION_PIPELINE.md): stable chroma-green references, one reference-guided video per continuous action, fixed-rate extraction, chroma removal, per-action union crop, shared 192×192 canvases, shared foot baselines, optimized alpha WebP frames, and literal GDScript preloads. The Warden intentionally reuses the coherent blade-guard motion set at a larger scale rather than introducing unapproved animation imagery; its larger capsule, desaturated armor body, red/gold directional rim, state telegraphs, and unique controller establish a separate boss identity while keeping the release package lean.

Every hero, blade-guard, and gunner frame receives a lightweight directional light pass from `shaders/character_rim.gdshader`. The shader derives its edge mask from the existing frame alpha, adds a cool-cyan key edge and hot-magenta bounce, and includes a narrow inner-edge response. **Rim Thickness** (`0.5–8.0 px`) and **Rim Brightness** (`0–1.5×`) are live controls in the Audio / Visual tab, making it possible to reduce the effect to a subtle edge or turn it off entirely. A reusable `CharacterRimLight` Sprite2D tracks the current texture, flip, scale, and 192×192 foot-aligned canvas without adding normal-map downloads.

Rain is simulated in world space using deterministic depth-layered drops with varied speed, length, opacity, drift, near-drop highlights, and floor splashes. The complete rain simulation advances with the same focus time scale as combat entities.

## Audio and storm feedback

Rooftop, tutorial, and interior exploration use the warmer **92-BPM lo-fi radio option A**: dusty boom-bap drums, Rhodes-like chords, restrained bass, shortwave tuning sweeps, carrier whine, signal flutter, and obvious static interference. The Warden combat uses a separate **128-BPM D-minor cyber-noir lo-fi theme** with a harder breakbeat, dirtier keys/synth, and radio static. Its 45-second 48 kHz stereo Vorbis runtime loop uses a 1.875-second circular crossfade, begins only when combat control and the HUD unlock, and stops for both the opening confrontation and post-defeat dialogue. Slash, parry, and elimination playback uses the three user-provided ElevenLabs sound-effect masters; player death intentionally reuses the same elimination cue as enemies. Small pitch variation prevents repeated combat sounds from feeling identical.

Lightning strikes occur at randomized intervals with a brief cool-white full-screen flash and subtle camera impulse. Slashes use minimal shake, successful parries and hits use a firmer impulse, defeat uses the strongest shake, and every impulse decays rapidly to preserve aiming clarity. **Every successful player parry—ordinary bullet, tutorial bullet, interior bullet, Warden bullet, or committed Warden melee—starts the universal impact response.** The supplied default is **0.30 real seconds at 0.5×** plus a separate **0.28-second, 0.02× zoom around the current screen center**. The zoom never adds a player-tracking displacement, so a moving or dash-slashing 影 cannot drag the composition sideways during the pulse. The player owns one unified time-scale path: internal Focus and the external parry scale are combined by taking the slower active value before movement, slash-dash distance, attack clocks, and animation clocks advance. The same combined scale drives enemies/Warden, projectiles, rain, particles, active/new SFX, BGM, and ambience; camera zoom uses real time so it punches in and releases independently. During Focus alone, gameplay remains at `0.34×`, while BGM and rain use the more musical `0.72×` pitch treatment. The former blue player-centered Focus ring remains disabled; only the restrained screen wash and HUD meter remain.

On death, the main run, tutorial combat, and Warden encounter freeze indefinitely on the fatal frame. A centered **“已死亡”** screen presents `R // 倒放` and `ESC // 返回标题画面`; rain, actors, enemies, projectiles, and forward ambience stay paused while the choice is visible. Pressing `R` now rewinds the **entire current attempt**, from the fatal frame to its initial snapshot. Source time is compressed into a bounded presentation: a 40-second attempt plays in 2 seconds, a 120-second attempt in 3.5 seconds, and a 200-second-or-longer attempt in 5 seconds. The recorder samples at 12 Hz and preserves at most 2,400 snapshots, progressively halving older temporal density when needed so long attempts remain Web-memory-safe while retaining their beginning and end. 影, enemies or the Warden, expired projectiles, animation clocks, and the camera all traverse recorded states backward; defeated runtime actors and bullets remain invisibly archived until the attempt ends so they can reappear during rewind. The reverse BGM is scrubbed over the same full source interval and mixed with band-limited signal noise. At the oldest snapshot, full-screen static becomes opaque, the room is rebuilt underneath it, and only then is the start revealed, removing the former visible jump. This is a complete visual state replay rather than interactive rollback: gameplay signals and collisions are not re-executed during playback.

## CRT presentation

The CRT filter is currently **disabled**. Its Web-compatible shader and layer remain in the project for possible later iteration, but the overlay is hidden at runtime, so the city, characters, effects, HUD, and tweak panel all render without scanlines, phosphor masks, color separation, curvature, grain, or vignette.
