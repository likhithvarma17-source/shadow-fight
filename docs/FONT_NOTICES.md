# Font Notices

## Fusion Pixel Font

**《影》** uses **Fusion Pixel Font 12px Proportional, Simplified Chinese (`zh_hans`)**, release **2026.08.11**, as its project-wide UI font.

| Field | Value |
|---|---|
| Project | [TakWolf/fusion-pixel-font](https://github.com/TakWolf/fusion-pixel-font) |
| Release | [2026.08.11](https://github.com/TakWolf/fusion-pixel-font/releases/tag/2026.08.11) |
| Selected package | `fusion-pixel-font-12px-proportional-otf.woff2-v2026.08.11.zip` |
| Bundled runtime file | `fusion-pixel-12px-proportional-zh_hans.woff2` |
| Copyright | Copyright (c) 2022, TakWolf (<https://takwolf.com>) |
| Font license | [SIL Open Font License 1.1](https://github.com/TakWolf/fusion-pixel-font/blob/master/LICENSE-OFL) |

The upstream project recommends the **proportional** variant for ordinary presentation because it has more natural spacing, line height, and mixed Chinese/Latin alignment. The font software may be embedded and redistributed with software under the OFL conditions. The original OFL text and upstream component license texts are included under `data/licenses/` and shipped in the Web package.

Godot applies the font through the project-wide **GUI > Theme > Custom Font** setting, following the engine’s documented project-level theme mechanism: [Introduction to GUI skinning](https://docs.godotengine.org/en/4.7/tutorials/ui/gui_skinning.html) and [Using Fonts](https://docs.godotengine.org/en/stable/tutorials/ui/gui_using_fonts.html).
